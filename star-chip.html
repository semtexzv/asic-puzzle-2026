From polygons to a solved puzzle

How the sky was recovered

  • Extract the netlist. KLayout traced the metal layers of puzzle.gds back into 728 standard cells and their wiring. ✓ matches the chip's I/O byte-for-byte
  • Read the architecture. 92 flip-flops, a serial-load state machine, one win comparator, and a message-ROM output stage.
  • Solve for the input. yosys + ABC found a trace to success; z3 proved it unique. ✓ verified in simulation
  • Recover the regions. The region counters are linear parity flops — probing them with single stars handed back all 11 regions. ✓ solution has 2 stars in every one
  • Close the loop. An independent solver, given only the recovered regions, returns the same grid — uniquely. ✓ region map == chip's, both directions
